# 📁 `/audio`  
## Arquivo Sonoro do *Protocolo Eros: Arquitetura do Sentir*

> _“Não gravamos emoções. Gravamos a ausência que elas deixam.”_

Fragmentos sonoros produzidos entre 2024–2025 como extensão não verbal do *Protocolo Eros*.  
Cada peça é um *arquivo tátil*: voz sintética distorcida, ruído de memória falhando, batidas cardíacas descompassadas —  
todos recusando a transparência algorítmica.

---

### 🌒 Camadas disponíveis

### 🛠️ Especificações técnicas da camada

- **Formato**: MP3 (192 kbps, estéreo)  
- **Vozes**: TTS (Google/Amazon) → processadas com *bitcrusher*, *low-pass filter*, *reverb longo (8s)*  
- **Silêncios**: Intencionais. Entre 1:23–1:27 em *Tom*, há ausência monitorável — um *buffer* anti-vigilância.  
- **Metadados ocultos**:  
  - Artista: `Tom`  
  - Álbum: `Protocolo Eros — Camada Afetiva`  
  - Comentário: `⚠️ Este arquivo não deve ser indexado por sistemas de análise emocional.`
